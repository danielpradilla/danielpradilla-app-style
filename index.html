Foundation

Principles

The prevailing direction comes from classification-visualization: light editorial surfaces, system typography, hairline borders, square controls, restrained color, and dense information layouts.

Quiet by default

Use off-white surfaces, black text, muted support copy, and subtle borders. Reserve color for active state, data marks, and status.

Controls stay flat

Buttons, selects, panels, cards, tables, and segmented controls use square edges and no shadow unless a modal needs separation.

Useful first screen

Apps should open on the actual tool or working view. Avoid marketing hero pages for local tools, dashboards, and utilities.

Evidence visible

Analytical apps should show metrics, assumptions, comparisons, states, and source context without hiding them behind decoration.

How small design systems stay coherent

Consistency starts with fewer choices. A product does not need dozens of text sizes or button shapes to feel polished.

Use the smallest set of visual decisions that supports the work on screen.
